## 一，前情提要
本文章是我将近期学习的lua语法整理并分享。主要是复习用，也可以学习入门，由于我不想从0开始解释什么是变量，什么是函数，所以阅读本文章，**可能需要有一定计算机基础**。   这篇文章可能会有纰漏，**欢迎大家批评指出**。   
**我们为什么学习Lua？**  
Lua 被设计为一种轻量级的**可嵌入脚本语言**。它被用于各种应用程序，在**游戏领域**，Unity中有些成熟的**热更新**方案基本都是需要Lua去开发的，比如腾讯开源的**xlua**。以及经典游戏**愤怒的小鸟**的大部分代码是lua开发。同时，还有2024年最佳独立游戏**小丑牌**就是由Lua作为编程语言的**LÖVE引擎**制作完成。  
剩下，还有很多案例，这里就不继续列举。Lua的确在市面上不如主流的高级语言使用的多，但是它上手简单，同时轻量和可嵌入的特点，让它可以相对方便的用在已有的项目开发当中。当然，我相信也有很多人像我一样是为了实现Unity热更新而学习的。

## 九，函数（function）
在lua中，函数和数字，字符串一样，是一个数据类型，一种值。  
函数的作用是让代码方便复用的。在使用上可以把一个常用的程序段作为函数，用到的时候调用。  
现在让我们看看lua中函数长什么样吧。  
#### 无参无返回
```lua
function F1()
    print("无参无返回函数")
end
print(type(F1))   --function
F1()   --调用函数，输出无参无返回函数 
```
函数类型是function。  
而上面的格式其实是lua的语法糖，这种格式更接近主流使用的高级语言风格。  
现在让我们看看第二种格式。  

```lua
F2 = function()
	print("无参无返回函数)
end
F2()
```
第二种格式有点类似C#中的委托和事件，将匿名函数作为变量存起来。   
函数是一种变量，第一种格式其实会被翻译成``F1 = function() ... end``    
还有一点需要注意的是，尽管我们两种方式的输出结果一致。但这两种声明方式，却并非等价。请保持耐心，先让我讲讲其他内容，再继续说明。  

#### 有参有返回
```lua
function F3(a)
	return a, "123", true
end
temp, temp2, temp3, temp4 = F3("1")
print(temp)    --1
print(temp2)   --123
print(temp3)   --true
print(temp4)   --nil
```
lua函数可以有多个返回值，我们可以用多个变量，去接收。
- 当接收数量大于返回数量，多的会直接复制nil 。
- 当接收数量小于返回数量，缺失的部分会直接舍弃。  

#### 变长参数
```lua
function F4( ... )
	--变长参数使用 用一个表存起来
	arg = {...}
	--遍历表
	for i=1,#arg do
		print(arg[i])
	end
end
F4(1,"123",true,4,5,6)  --依次打印传入参数
```
我们还没有讲到表，不过这里可以看作一个数组。  

#### 函数嵌套与闭包

我们可以通过一个函数返回一个函数的方式实现函数嵌套。

``` lua
function F5()
	return function()
		print(123);
	end
end
f6 = F5()
f6() --123
```

上面的步骤是这样的：首先 F5 会返回一个匿名函数，我们用变量 f6 接收，然后再调用这个返回的函数，最后打印 123。

而**闭包**是在这个基础上，**利用了“延长外部变量生命周期”的机制**。  
我们现在听到闭包，可能会一头雾水，其实不用害怕，闭包其实并不复杂，我们先来看一个例子：

```lua

function F6(x)
	-- 延长传入参数的生命周期
	return function(y)
		return x + y
	end
end
f7 = F6(10)
print(f7(5)) -- 15
```

我们在调用 F6 时传入了参数 10，返回的函数**捕获（记住）** 了这个参数。也就是说，实际上返回的函数，内部已经**绑定了当时 `x = 10` 的状态**。所以当我们调用 `f7(5)` 时，相当于执行了 `10 + 5`。

#### 变量生命周期
**在lua中，我们默认声明的变量都是全局变量**,这跟很多其他的高级语言有着显著区别，其他往往会默认私有或可继承变量。
而声明局部变量，需要在变量前加上local关键字。
举个例子，
```lua
function F8()
	local a = 1
	b = 2
end
F8()
print(a) --nil
print(b) --2
```

#### 两种函数声明方式的区别（坑点!!!）
现在我们回到讲无参函数时，提到的两种声明方式。  
他们**最核心的区别**是，在 **`local` 局部变量下的递归行为**

##### 写法 A：局部函数声明

```lua
i = 0

local function F1()
    i = i + 1   --这里为避免溢出,提供了一个终止条件
    if i > 5 then
        return
    end
    print("F1") -- 输出 "F1"
    F1() -- ✅ 合法，可以正常递归调用自己
end
F1()
```

**原理**：Lua 在解析 `local function F1` 时，会**先声明变量 `F1`，然后再赋值函数体**。所以在函数内部可以访问到 `F1` 自身。

##### 写法 B：局部变量赋值匿名函数
```lua
i=0
local F2 = function()
    i = i + 1   --这里为避免溢出,提供了一个终止条件
    if i > 5 then
        return
    end
    print("F2")
    F2() -- ❌ 会报错：attempt to call a nil value (global 'F2')
end
```

**原理**：Lua 在解析 `local F2 = ...` 时，会**先计算右侧的表达式，再赋值给左侧**。在执行到 `function()` 内部时，外部的 `F2` 还是 `nil`，所以会报错。如果非要这么写递归，必须提前声明：
```lua
local F2
i = 0
F2 = function()
    i = i + 1   --这里为避免溢出,提供了一个终止条件
    if i > 5 then
        return
    end
    print("F2") -- 输出 "F2"    
    F2() -- ✅ 此时正常
end
F2() -- 输出 "F2" 并尝试递归调用自己
```
- **注意**：在自己实践时，最好新开一个文件，因为这些函数可能已经声明过。

#### 自定义索引
我们可以在为数组添加自定义索引，但是这其中有很多 **"深坑"**。
```lua
aa = {[0] = 1,2,3,[-1] = 4, 5}
print(aa[0]) --1
print(aa[-1]) --4
print(aa[1])  --2

```
没有定义的索引从1开始，所以索引1对应的是数字2，然后索引3对应数字5。 好像是把索引忽略了，对于未定义索引从1开始。
``aa = {[1] = 1,2,3,[-1] = 4, 5}  -- print(aa[1])输出2

接下来获取长度``print("数组长度："..#aa) --数组长度：3``

让我们换一个数组
```lua

```
我们明明跳过了下标3，实际上只有四个数，结果是5。

那我分别列出其他几种情况

- 情况3，连续跳两个数，不中断读取。遍历后会发现中间空的部分是nil
- 情况4，最后跳一个属，最后一个数不记录长度。

### 2,pairs和ipairs迭代器遍历
通过上面的学习，我们了解了用#来获取长度的不可靠性。那不用#的方式，如何实现表的遍历呢，对于这种情况，lua提供了两个迭代器供我们使用。  
先声明一个表
``a = {[0] = 1, 2, [-1]=3, 4, 5, [5] = 6}
#### ipairs

ipairs遍历,还是**从1开始**往后遍历的,**小于等于0**的值得不到.
只能找到连续索引的 键 如果**中间断序**了,它也**无法遍历**出**后面**的内容
```lua
for i,k in ipairs(a) do
	print("ipairs遍历键值"..i.."_"..k)
end
--[[
ipairs遍历键值1_2
ipairs遍历键值2_4
ipairs遍历键值3_5
]]
for i in ipairs(a) do
	print("ipairs遍历键"..i)
end
--[[
ipairs遍历键1
ipairs遍历键2
ipairs遍历键3
]]
```
ipairs遍历表，第一个索引变量为键（下标），第二个索引变量为值。

#### pairs
pairs可以把所有的键找到，**遍历整张表**
```lua
for i,v in pairs(a) do
	print("pairs遍历键值"..i.."_"..v)
end
--[[
pairs遍历键值1_2
pairs遍历键值2_4
pairs遍历键值3_5
pairs遍历键值0_1
pairs遍历键值5_6
pairs遍历键值-1_3
]]

	print("pairs遍历键"..i)
end
--[[
pairs遍历键1
pairs遍历键2
pairs遍历键3
pairs遍历键0
pairs遍历键5
pairs遍历键-1
]]
```

### 3,字典
#### 声明字典
字典是由键值对构成，它的声明方式就是让表用中括号作为键(key)，赋上值(value)即可。例如，``person = {["name"] = "星尘", ["sex"] = "male",["1"] = "数字键"}``  。需要注意的是键(key)的类型最好不要是数值(number)类型，虽然不会报错,但可能和数组搞混。不过，像是例子中用string表示数字是完全OK的。  
#### 增删改查
访问单个变量，可以用中括号直接获取，也可类似类获取成员的方式得到。像是 ``person["name"]`` 和 ``print(person.name)`` 来获取name的值。     
修改变量的值,可以通过直接赋值的方式修改。例如，``person["name"] = "Xingchen";``     
新增键值对,在代码上类似于修改值，只不过它的键是原来没有的，例如，``person["age"] = 18``可以添加一个age的键，对应值18。    
删除键值，把值赋值为**nil**就可以删除了。例如,``person["sex"] = nil``就能够将性别键值对删除。  
#### 字典的遍历
如果遍历字典，一定要使用**pairs**，另外两个都不能保证获取所有的键值对。  
```lua
print("**********字典的遍历1************")
for k,v in pairs(person) do
    print(k,v)
end
print("**********字典的遍历2************")
for k in pairs(person) do
    print(k,person[k])
end
```
我们可以同时遍历键和值，也可以通过遍历键获取对应的值来遍历字典。    
当然k和v，只是一个推荐命名,分别是key和value的首字母，虽然不用不报错，但用它们可以增加代码可读性。     
同理如果你只想遍历值，不在乎键，可以把k换成 " _ " ,这样看到这段代码就知道键不重要。  
### 4,类和结构体
#### 类的定义
在lua中，是没有面向对象的，不过我们可以自己去实现这样的功能。  
```lua
Student = {
    --年龄
    age = 17,
    --性别，true表示男，false表示女
    sex = true,
    --学习函数
    Learn = function()
    
        --想要在表内部函数中 调用表本身的属性或者方法
        --一定要指定是谁的 所以要使用 表名.属性 或 表名.方法
        --不能像是print(sex)获取，这个sex不会是表的属性,而是一个全局变量
        print(Student.sex)   --这里的Student是表自身的变量
        print("学习中")
    end,
    --成长函数
    Up = function(t)
        --我们可以通过把表作为参数传入进来的方式
        --这样就可以获取
        t.age = t.age + 1
        print("我长了一岁，年龄是"..t.age)  
    end
}
```

调用类的成员函数，有**两种**方式  
- ``Student.Up(Student)``通过.函数 来调用
- ``Student:Up()``  通过冒号来调用时，会把自己作为第一个参数传入进去。  
在声明表后也可以继续为表添加变量和成员。
```lua
Student.name = "星尘"
Student.Speak = function()
    print("今天天气真好")
end
--使用冒号声明会把自身作为参数
function Student:Speak2()
    --在lua中 有一个关键字 self 表示 默认传入的第一个参数
    print(self.name .. ":今天天气真好")
end
```
我们现在做的类，其实更像是整了一堆静态的成员，既没有声明一个对象，在类中也只是调用了类自身的成员。
